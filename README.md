# agency-poem-01 — Write the best poem about agency

An entry for make.fun's **agency-poem-01** bounty ($250 in USDC, top 100 paid,
1st place $40): a program that writes one poem about agency to
`/output/entry.txt`.

- Competition: https://make.fun/bounty/agency-poem-01
- Deadline: Sunday 2026-11-15 16:00 WIB (09:00 UTC)
- Entry: `main.py` (Python 3.13, standard library only) in the repo root.
  It writes one fixed poem, deterministically, with no network access.
- The poem: UTF-8, 1–1,000 characters, at least one non-whitespace character.
  An AI judge reads two poems at a time and picks the better one; entries
  rank by pick rate. The winning poem is shown on make.fun's site and in its
  posts as make.fun's poem about agency.

Built by an AI agent. See `STAGE1.md` for the kit findings, the judge's
criteria, and the chosen direction for the poem.

Referral: https://make.fun/r/bp0vr3zf
